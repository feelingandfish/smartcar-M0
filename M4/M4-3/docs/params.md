# M4-3 速度环 PID —— 参数与设计说明

## 2. 编码器计数换算

- 磁环每圈 **7 个脉冲**
- TIM2 编码器模式 **TI1+TI2 四倍频** → 电机轴每圈 7×4 = 28 计数
- 减速比 **1:50** → 输出轴每圈 **1400 计数**
- `#define ENC_COUNTS_PER_REV 1400`

10 ms 采样窗口：

```
rpm = delta / 1400 * 60 / 0.01 = delta * 6000 / 1400
```

## 3. PWM 频率

- TIM3：PSC=7，ARR=99 → 8 MHz / 8 / 100 = **10 kHz**
- 依据：
  1. 10 kHz 在可听声（20 Hz~20 kHz）之外，电机不会啸叫；太低（如 1 kHz）会落进可听范围啸叫，且开关周期变长、电流纹波变大；
  2. 开关周期 0.1 ms 远小于 N20 电机的电气/机械时间常数（ms 级），电流纹波小、转矩平滑；
  3. 远低于 TB6612 的 100 kHz 上限，开关损耗可控；太高会增加 MOS 开关损耗、驱动发热；
  4. ARR=99 提供 1% 占空比分辨率，调速够细。

## 4. 控制周期 10 ms

- TIM4：PSC=79，ARR=999 → 8 MHz / 80 = 100 kHz，/ 1000 = **100 Hz = 10 ms**
- 由 **TIM4 更新中断** 触发（`HAL_TIM_Base_Start_IT(&htim4)`），不是 delay 凑周期。
- 周期自检方法：中断里每 10 ms 翻转一次 PC13，示波器测方波周期应为 20 ms（上升沿间隔 10 ms）；或看串口 CSV 的 t 列是否严格每行 +0.010。

## 5. 测速更新率与控制周期的关系

- 本设计测速窗口 = 控制周期 = 10 ms（每次进中断读一次 TIM2 计数增量）。
- 如果测速窗口比控制周期慢（例如 100 ms 才更新一次），反馈值会滞后于真实转速，相当于在闭环里串了一个延迟环节，相位滞后增大，闭环容易振荡、超调变大。
- 两者一致时没有额外滞后，是"每 10 ms 拿一次最新转速"。

## 6. 位置式 vs 增量式（选位置式）

**位置式**（本设计选用）：

```
u(k) = Kp*e(k) + Ki*Σe + Kd*(e(k)-e(k-1))
```

**增量式**：

```
Δu(k) = Kp*(e(k)-e(k-1)) + Ki*e(k) + Kd*(e(k)-2e(k-1)+e(k-2))
```

区别：

| | 位置式 | 增量式 |
|---|---|---|
| 输出 | 直接给绝对控制量（PWM 占空比） | 给控制量增量，需自己累加 |
| 积分 | 误差累加，会积分饱和，必须抗饱和 | 没有显式积分项，天然无 windup |
| 限幅 | 直接对输出限幅，直观 | 要对累加后的输出限幅，处理绕 |
| 切换 | 手自动切换冲击大 | 冲击小 |

**选位置式的理由**：执行器是 PWM 占空比（绝对量），位置式最直接；且考题要求"必须做抗积分饱和"，位置式正好能把积分限幅和条件积分讲清楚。

## 7. 抗积分饱和（隐藏考点）

`pid.c` 里做了两层：

1. **积分限幅**：`integral` 夹在 `[out_min, out_max]` 之间；
2. **条件积分**：先预判 `P + integral + D` 是否已经超出输出限幅，若已饱和则本周期**不再累加积分**（防止误差持续累加把积分项撑爆）。

为什么必须做：目标从 60 突然降到 0 时，误差 e 长期为负（或正），积分项会一直朝一个方向累加；等转速降下来、误差反号时，巨大的积分项要很久才能"吐"回来，表现为**反向冲过头 + 长时间才恢复**。现场一眼就能看出来。

## 8. 纯 P 为什么有稳态误差

稳态时转速不变，d/dt = 0，电机仍需要一定 PWM 来克服摩擦和负载：

```
u_ss = Kp * e_ss
```

要输出这个 `u_ss`，就必须存在非零误差：

```
e_ss = u_ss / Kp ≠ 0
```

所以只要 Kp 有限，纯 P 一定有稳态误差；Kp 越大误差越小，但太大就会振荡。

## 9. 加了 I 之后超调怎么压

- 减小 Ki（积分作用放慢）；
- 加 D（微分提供阻尼，抑制超调）；
- 积分分离（误差很大时不积分）；
- 抗积分饱和（本设计：积分限幅 + 条件积分）。

## 10. D 对噪声敏感在曲线上的表现

微分项 `Kd*(e(k)-e(k-1))/dt` 里 `dt=0.01` 很小，会把编码器量化噪声放大 100 倍左右：曲线表现为**转速和 PWM 高频抖动**、稳态波动变大。缓解办法：Kd 取小、对微分加低通（不完全微分）、或对转速反馈先滤波。

## 11. 捏停期间积分项在做什么

手捏停轮子时实测转速掉到 0，误差 `e = target - 0 = target` 很大且持续为正，位置式的积分项一直在**累加变大**；若没有抗饱和，积分会一路涨到远超输出上限（windup）。

## 12. 无抗饱和松开后的现象

积分项已经累积得非常大，松手瞬间控制器仍输出接近满占空比，转速会**冲过目标很多**（大超调），随后积分要反向"吐"很久，表现为**来回振荡、恢复很慢**。有抗饱和时，饱和期间不积分，松手后能快速回到目标。

## 13. "跟得紧"和"抗扰好"是否矛盾

是矛盾的，二者都靠提高增益，但：
- 跟得紧（上升快、稳态误差小）需要大 Kp / 大 Ki；
- 抗扰好（扰动后恢复快、不振荡）也需要快速响应，但增益太大会让闭环相位裕度变小，扰动一来就振荡。

实际是折中：在保证不振荡（有足够相位裕度）的前提下尽量提高增益。本项目的整定思路就是"先加 Kp 到临界振荡，再退一点，然后加 Ki 消稳态误差，最后少量 Kd 压超调"。
