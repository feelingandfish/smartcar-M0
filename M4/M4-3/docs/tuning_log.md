# M4-3 PID 整定与实验记录

## 实验平台与记录口径

- STM32F103C8T6 + TB6612 A 通道 + GA12-N20 带 AB 编码器减速电机（减速比 1:50，电机标称额定 6 V）。实验用标称 7.4 V 电池供驱动板 VM；未用万用表测量带载端电压。STM32 由 ST-Link USB 供电；逻辑电源与电机电源用途不同，控制器/驱动器/电池负极/USB-TTL 共地。
- 编码器每圈输出轴计数的计算理论值为 1400 counts/rev；程序沿用 M4-2 实测 `1385 counts/rev`。测速/控制名义周期为 10 ms，`rpm = delta_cnt × 6000 / 1385`。
- TIM3 PWM 频率 10 kHz；软件输出限幅 ±500。PID 为位置式，包含积分限幅、条件积分抗饱和和微分低通滤波（alpha=0.3）。
- 阶跃组统一目标 60 r/min。`data/step_metrics.csv` 的稳态误差/波动按末尾 3 s 统计；稳态误差定义为“目标−平均转速”，波动为相对该段平均值的最大绝对偏差。10 ms 上升时间仅作采样精度受限的估算。

### 2.3 必须回答的问题

1. **纯 P 为什么有稳态误差？** 稳态时微分为零，纯 P 只能输出 `u=Kp×e`。电机需要非零 PWM 克服摩擦和负载；只要 Kp 有限，要产生这个维持输出就需非零误差，近似 `e_ss=u_ss/Kp`。本次 P 组的末尾平均速度约45.95 r/min，目标60 r/min，误差约14.05 r/min。
2. **加 I 后超调变大怎么压？** 积分会累加过去的误差；接近目标时先前积下来的量仍可能继续推电机，形成超调。可减小 Ki、增加适量 D 阻尼，并使用积分限幅/条件积分。此次 PI 和 PID 都出现约8.3%峰值超调；本次结果没有证明 D 已降低峰值。
3. **D 对噪声敏感吗？曲线体现了吗？** D 对误差快速变化敏感，可能使 PWM/速度高频抖动。曲线有小幅快速波动，但编码器10 ms计数分辨率约4.33 r/min/计数，量化本身就会产生跳动；不能据此认定波动都是 D 导致。程序使用 alpha=0.3 的低通微分。末尾3 s 波动从 PI 的±7.42降到 PID 的±5.42，但单次记录不足以证明因果。

## 2.4 手动阻停抗扰（实测现象）

做法是闭环在目标附近运行时手动阻停轮子/输出端，再松开；不是把目标命令改成0。观测指标按记录中 PWM 是否达到 ±500、松开后首次回到目标及是否超过目标记录。首次到达不等于稳定时间；各组初始状态与阻停时长不完全相同，适合报告各自现象，不适合做严格排名。

| 组 | 参数 | 阻停时 PWM 到限幅 | 松开后首次到达目标 | 是否超过目标 | 记录说明 |
|---|---|---|---:|---|---|
| P | Kp=13, Ki=0, Kd=0 | 是 | 30 ms | 是 | 该时间是首次采样到目标，不代表随后稳定 |
| PI | Kp=13, Ki=1, Kd=0 | 是 | 50 ms | 是 | 扰动前未完全稳定，需结合原始曲线 |
| PID | Kp=13, Ki=1, Kd=0.01 | 是 | 6.29 s | 是，记录峰值65 r/min | 多次短暂停转/再启动；扰动前平均约47.95 r/min，非同起点对照 |

实测 PID 阻停记录 `data/disturb_PID.csv` 的末尾3 s平均约59.11 r/min、范围52–65 r/min。阻停期间转速接近0，误差增大，PWM到软件限幅。松开后PID第一次达到目标需6.29 s，但此后仍有波动。实验条件不完全相同，不能将组间恢复时间差完全归因于 PID 参数。

**抗饱和解释：**积分项按误差累加；代码通过积分上下限和条件积分，避免输出已经饱和时误差仍把积分继续推向饱和方向。若没有抗饱和，长时间停转可能累积较大积分；松开后可能持续输出较大 PWM，出现冲过头或退回较慢。关闭/开启抗饱和的短记录不是同条件对照，所以仅作原理和现象说明，不下定量优劣结论。
