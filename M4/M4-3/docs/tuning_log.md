## 实验条件

- 电机：GA12-N20 直流减速电机，减速比 1:50

- 驱动：TB6612（A 通道），STBY 接 3.3V
- 控制周期：10 ms（TIM4 更新中断）
- 采样：USART1 115200 8N1，每 10 ms 输出一行 `t,target_rpm,actual_rpm,pwm`
- 目标转速：60 r/min（阶跃）

## 抗扰实验（任务 2.4）

记录口径：以最后一段连续 `delta_cnt=0` 后的第一个非零计数作为松开时刻，以之后首个 `actual_rpm >= 60 r/min` 的采样点作为首次恢复到目标。该时间不代表稳定时间。输出限幅为 `±500`。

| 组 | 参数记录 | PWM 是否到上限 | 首次恢复到目标 | 松开后是否过冲 | 说明 |
|---|---|---|---|---|---|
| P | Kp=13, Ki=0, Kd=0 | 是 | 30 ms | 是 | 首次达到，未稳定 |
| PI | Kp=13, Ki=1, Kd=0 | 是 | 50 ms | 是 | 首次达到，未稳定；扰动前未稳定在 60 r/min |
| PID | 按实验参数截图记录 Kp=13, Ki=1, Kd=0.01 | 是 | 6.29 s | 是 | 首次达到，未稳定；本次记录有多次短暂停转/再启动 |

PID 原始记录：`data/disturb_PID.csv`，对应桌面文件 `SAVE2026_11_14_22-12-51.DAT`。共 5041 个样本，`0.01–50.41 s`。最后一段持续无计数区间为 `5.66–7.06 s`；首个非零计数在 `7.07 s`；首个达到或超过 60 r/min 的点在 `13.36 s`，因此恢复时间为 `13.36−7.07=6.29 s`。最大转速 `65.0 r/min`，目标为 60 r/min，超调量为 `8.3%`。最后 3 s 平均转速 `59.11 r/min`，范围 `52.0–65.0 r/min`。PWM 最大值 `500`，达到输出上限。

**数据局限：**PID 组在明显受阻前的 `0.10–4.96 s` 平均转速为 `47.95 r/min`，未稳定在目标 60 r/min；日志还显示数次短暂停转和重新转动。因此这组可记录“限幅、首次恢复时间、过冲”，但与 P、PI 不构成严格同起点对照。DAT 不包含增益确认行；当前 `src/main.c` 文件内 `PID_TEST_MODE=1` 且默认 P 参数为 `2/0/0`，与此前 PID 参数截图不同。应核对实验时实际烧录版本，不能仅凭 DAT 认定运行时增益。

## 整定步骤（顺序）

1. Ki=0、Kd=0，只加 Kp，从小往大加，直到转速能跟上、略有振荡；
2. Kp 退一点（约 80%），加 Ki 直到稳态误差消失，Ki 从 1~2 起；
3. 超调明显时加 Kd（0.01~0.1 量级），边加边看稳态抖动，抖了就减；
4. 复查阶跃和抗扰，取折中值。
