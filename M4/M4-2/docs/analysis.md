# M4-2 毛刺归因与参数选择依据

> 本文只记录目前已有代码、串口记录和 VOFA+ 桌面对比能够支持的结论。没有做过的对照实验不写成已验证结论。

## 1. 测试对象与现象

- 主控：STM32F103C8T6。
- 传感器：独立 MPU6050 模块，通过 I2C 读取。
- 本阶段做的是独立模块测试，没有连接电机，因此曲线中的波动不能归因为电机振动。
- 静止测试时，将模块平放在桌面上；观察到曲线只有很小的起伏。
- 手动转动测试时，VOFA+ 曲线上出现了尖刺和不规则波动。桌面静止曲线相对平稳，因此当前将尖刺主要归因于手持转动时手部抖动、转动速度不均，以及传感器姿态突然变化。

该归因是基于“桌面静止”与“手动转动”两种现有曲线的对比。它说明手动操作是目前最可能的来源，不等同于已经通过降低采样率、改变 I2C 速率等实验排除了所有其他因素。当前记录中没有足够证据把尖刺判定为 I2C 读失败或量程削顶。

## 2. 两种曲线状态的观察

### 2.1 转动停止后的变化

现有曲线没有观察到一个明显、独立且可重复的“停止后回弹”过程；停止手动转动后，曲线逐步回到接近静止时的状态。由于当前测试是手持操作，停止动作本身也可能带来轻微晃动，因此不把短暂变化定量归因于互补滤波权重或加速度计瞬态。

### 2.2 周期性小波动

桌面静止时只有很小的起伏；手动转动时波动不规则。现有记录没有显示稳定、重复的周期性波形，因此不能据此认定存在与某个固定频率同步的机械振动或采样拍频。

## 3. 参数与选择依据

| 参数 | 当前设置 | 依据与含义 |
|---|---:|---|
| MPU6050 加速度量程 | ±2 g | 适合观察重力分量和较小的手动运动；灵敏度较高。若运动加速度超过量程会削顶，当前曲线没有完成削顶专项验证。 |
| MPU6050 陀螺仪量程 | ±250 °/s | 适合较慢的手动转动，角速度分辨率较高；快速转动超过量程时可能削顶。 |
| 加速度换算系数 | 16384 LSB/g | ±2 g 配置对应的标称灵敏度。物理加速度 = 原始值 ÷ 16384。 |
| 陀螺仪换算系数 | 131 LSB/(°/s) | ±250 °/s 配置对应的标称灵敏度。角速度 = 原始值 ÷ 131。 |
| MPU6050 读取周期 | 10 ms，目标 100 Hz | 每 0.01 秒更新一次传感器数据，给角度融合提供较密集的输入。 |
| 普通串口状态输出周期 | 100 ms，约 10 行/秒 | 用于查看实时状态；它低于内部传感器更新率。串口记录的行间隔不能误写成 100 Hz。 |
| 静置漂移记录周期 | 1000 ms，约 1 行/秒 | 便于记录约 60 秒漂移数据，形成易读的 CSV。 |
| I2C 速率 | 100 kHz | 当前工程配置值。没有做 100 kHz 与 400 kHz 的效果对比，所以不声称它是最优值。 |
| UART | USART1，115200，8-N-1 | 与 SSCOM/USB-TTL 串口设置相匹配，用于接收文本数据。 |
| 陀螺仪零偏校准 | 启动时静置采 200 个样本 | 对静止样本求平均，作为各轴零偏估计，再从后续角速度中减去。测试校准时应让模块保持不动。 |
| 互补滤波系数 α | 0.99 | 每次更新主要采用陀螺仪积分结果，并用加速度计角度作小比例长期修正。α 越大越信任陀螺仪短时变化，越小越信任加速度计。0.99 是当前工程值，并未通过 α 多组对照证明为最优。 |
| 编码器每输出轴一圈计数 | 1385 count/rev | 当前按此前手动转动一圈的实测记录作为暂用换算值；理论估算 1400 count/rev 与实测值接近。手动计圈和端点识别会引入误差，故应在报告中注明实测方法与局限。 |

## 4. 已有漂移数据能说明什么

已有约 60 秒静置数据中，融合角度变化远小于陀螺仪单独积分角度变化：

- 陀螺仪单独积分：约从 73.057° 变到 132.512°，变化约 +59.455°。
- 使用静止零偏补偿后的陀螺仪积分：约从 73.057° 变到 95.913°，变化约 +22.856°。
- 互补融合角度：约从 73.057° 变到 73.309°，变化约 +0.252°。

这组数据说明：在这次静置测试和当前参数下，零偏补偿减小了陀螺仪积分漂移，互补融合又利用加速度计方向信息进一步抑制了角度漂移。它不能单独证明 α=0.99 对所有运动都最优，也不能替代对不同 α 的正式对照实验。

## 5. 证据边界与后续验证

1. 手动转动曲线中的尖刺目前主要归因于手持操作造成的抖动和速度不均；要进一步验证，可固定传感器并重复转动，或用夹具保持转轴与速度更稳定。
2. 当前没有看到明显的停止后回弹，也没有看到稳定的周期性小波动；这表示本次记录未观察到明显现象，不代表任何情况下都绝不会出现。
3. 若要确认 I2C 是否造成尖刺，应同时记录 I2C 错误计数或失败日志，并在固定姿态下重复采集；仅凭曲线截图无法证明 I2C 完全没有问题。
4. 若要确认量程没有削顶，应检查原始加速度和角速度是否长时间接近量程满量程；当前归档曲线不足以完成这一判断。
5. VOFA+ 当前显示的四条曲线用于观察加速度角度、陀螺仪角速度、陀螺仪积分角度和融合角度。它是展示曲线，不是包含六轴原始量的 `rotate_once.csv`。

## 6. 当前结论

本阶段观察到：桌面静止时数据较平稳，手持转动时出现尖刺和不规则波动，最可能与手动操作带来的抖动和转动不均有关。当前没有观察到明确的停止后回弹或稳定的周期性小波动。参数选择依据来自 MPU6050 量程对应的标称灵敏度、当前工程配置和已有 60 秒静置漂移数据；没有进行过的参数对照不作为已验证结论。
